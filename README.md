# My-space-travel-game-written-in-Java-Script
This is a small video game that I made in 12th class in high school. You can go to different planets like sun, mars and moon in the game. There is a black hole that can bring you to any planet you want to go to. I used the some random trick to simulate the flame at the end of the rocket and to simulate the crash, when the rocket is to close to a planet. I think the background "stars" is an important element to make it looks more like in space.

To run the game, download all the .java file into one folder and open the file called main.jave in vs-code (or any other editor, but I not sure they will work properly since I have only run them on vs-code. Then click run and debug to run the game.

You can also watch the video demo about the game on Youtube: https://youtu.be/l9ROdBGInxc
